## 1. SBT#+ — 배달 뛰면 신용이 쌓인다

| 항목 | 내용 |
|------|------|
| **링크** | [milgram](https://www.milgram.io/community/kfip2026/projects/8abe80e5-57f8-4d08-a60a-c52009d1af27) |
| **조회수** | 287 |
| **핵심 아이디어** | 긱워커(배달 라이더) 노동 행동 데이터 → AI 분석 → Trust Score 산출 → XRPL Credential 발급 |
| **타겟** | 한국 230만 긱워커 (배달 라이더 우선) |

### 솔루션 상세
- 라이더가 **라이더첵 앱**에서 매일 정산 스크린샷 업로드
- **GPT-4o-mini**가 플랫폼/금액/건수 자동 분석 → 데이터 축적
- 3개월+ 축적 시 **Trust Score** (0~1000, 4등급) 산출
- XRPL **CredentialCreate**로 온체인 발급

### XRPL 활용 방식
| 기능 | XRPL 네이티브 기능 |
|------|-------------------|
| 신용 인증 발급 | `CredentialCreate` (발급/갱신/폐기/만료) |
| 금융 접근제어 | `DepositPreauth` (등급 기반 접근 허용/거부) |
| 데이터 무결성 | 주간 **Merkle Root** → `DIDSet`으로 앵커링 |
| 크로스보더 | 배민→쿠팡이츠→인도네시아 Grab까지 확장 가능 |

### 차별점
- 프로토타입 이미 존재: [kfip-sbtplus.vercel.app](https://kfip-sbtplus.vercel.app/)
- 구글 앱스토어 '라이더첵' 앱에 기능 추가 예정
- AML/KYC/트래블룰 규제 영역 **비해당** (자금 이동 X, 신용 기록 발행)
- 페르소나 3가지로 구체적 시나리오 제시 (민수/지훈/영호)

### 📊 위협도: ⭐⭐⭐⭐ (높음)
> 완성도 높은 프로토타입 + 구체적 페르소나 + XRPL 네이티브 기능 활용 극대화. 실제 서비스화 가능성 있음.

## 2. Fleet Settlement Mesh

| 항목 | 내용 |
|------|------|
| **링크** | [milgram](https://www.milgram.io/community/kfip2026/projects/2cc8a597-a40a-4269-83d1-f7fa26c632d5) |
| **핵심 아이디어** | 전기차 Fleet 충전 → 글로벌 5초 실시간 정산 인프라 (XRPL 기반) |
| **타겟** | 전기차 Fleet 운영사, 충전소 사업자 |

### 솔루션 상세
- 전기차 Fleet이 **전 세계 어디서 충전**해도 30일 기다릴 필요 없이 **5초 만에 정산**
- XRPL 블록체인 기반 실시간 크로스보더 정산

### XRPL 활용 방식
- 실시간 결제/정산 (빠른 트랜잭션 속도)
- 크로스보더 결제 (글로벌 Fleet 운영)

### 📊 위협도: ⭐⭐⭐ (중간)
> B2B 영역으로 데모 구현이 어려울 수 있음. 하지만 실제 EV 시장 성장과 맞물리면 강력.

## 3. 가디언월렛 (Family Guardian Wallet)

| 항목 | 내용 |
|------|------|
| **링크** | [milgram](https://www.milgram.io/community/kfip2026/projects/856c0dcf-51ce-4665-bcfd-e261395a2569) |
| **핵심 아이디어** | 인지저하 시니어 자산 보호 → 가족 2/3 승인 멀티시그 지갑 |
| **타겟** | 고령화 사회의 시니어 + 가족 |

### 솔루션 상세
- 인지저하 시기 시니어의 자산을 **가족 2/3 승인**이 있어야만 인출
- XRPL **멀티시그** 네이티브 기능 활용

### XRPL 활용 방식
- **MultiSign** (다중 서명 트랜잭션)
- 가족 구성원 키 관리

### 📊 위협도: ⭐⭐⭐ (중간)
> 사회적 임팩트 강함 (고령화 + 보이스피싱 방지). XRPL 멀티시그 네이티브 활용이 깔끔. 다만 UX 구현 난이도 있음.

## 5. XRP 무역대금 결제시스템

| 항목 | 내용 |
|------|------|
| **링크** | [milgram](https://www.milgram.io/community/kfip2026/projects/2951be61-cdd4-46e4-a6e4-cb2e83096eb2) |
| **핵심 아이디어** | AI 기반 바이어-업체 매칭 → 글로벌 전시회 상담 → XRP 무역대금 결제 |
| **타겟** | 스타트업 해외 진출 기업, B2B 무역 |

### 솔루션 상세
- AI가 국내업체-바이어 간 **적격 파트너 추천**
- 온/오프라인 상담 알선 (글로벌전시회)
- **XRP 무역대금 결제**
- XRP 결제 업체를 비즈니스 파트너로 **우선 추천** → XRP 생태계 확장

### XRPL 활용 방식
- 크로스보더 결제 (무역 대금)
- XRP 결제 인센티브 시스템

### 📊 위협도: ⭐⭐ (보통)
> 범위가 넓어 해커톤 수준에서 데모 구현 어려울 수 있음. B2B 무역은 진입장벽 높음.

## 6. SIVAX — 구조화 수익 서비스

| 항목 | 내용 |
|------|------|
| **링크** | [milgram](https://www.milgram.io/community/kfip2026/projects/6319d876-0392-49cc-8382-76612a92081a) |
| **핵심 아이디어** | XRPL 기반 구조화 금융상품 온체인 구현 → XRP를 운용 가능한 투자 자산으로 전환 |
| **타겟** | 디지털 자산 투자자 |

### 솔루션 상세
- 지갑을 통해 **상품 구조/리스크/수익 조건** 명확하게 확인
- **청약 → 정산** 전 과정 투명하게 온체인
- RLUSD 기반 정산, RWA 확장, AI 포트폴리오 운용 로드맵

### XRPL 활용 방식
- 구조화 금융상품 온체인 구현
- RLUSD 정산
- RWA(실물자산 토큰화) 확장

### 📊 위협도: ⭐⭐⭐ (중간)
> DeFi/RWA 트렌드와 맞물림. RLUSD 활용 언급으로 XRPL 생태계 기여 의지 보임. 규제 리스크 존재.

## 7. BlueLog — AI 보컬 피드백 & 크리에이터 생태계

| 항목 | 내용 |
|------|------|
| **링크** | [milgram](https://www.milgram.io/community/kfip2026/projects/7260c977-328e-4a36-bc80-a5d2bfd23581) |
| **핵심 아이디어** | 멀티모달 AI 보컬 분석 + 가창 데이터/성공경험 → RWA/NFT 디지털 자산화 |
| **타겟** | 보컬 학습자, 크리에이터, AI 데이터 시장 |

### 솔루션 상세
- 20년차 IT 아키텍트의 **BlueScore** 정밀 진단 엔진
- **BlueCast** 크리에이터 창작 도구
- 가창 데이터/지식을 **RWA/NFT**로 전환하여 유통
- **8건 특허** 기술 + BlueScore 앱 출시 완료

### XRPL 활용 방식
- NFT/RWA 토큰화 (가창 데이터 자산화)
- 지식 거래 마켓플레이스

### 📊 위협도: ⭐⭐ (보통)
> 특허 8건으로 기술력 인정 가능. 다만 XRPL 활용이 NFT 발행에 그칠 수 있음. 금융 혁신과 연결 약함.
