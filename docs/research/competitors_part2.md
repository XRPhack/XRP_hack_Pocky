| **타겟** | 크립토 밋업 참가자, 데이팅 사용자 |

### 솔루션 상세
- 참가 신청 → **DORRI 토큰 XRPL Escrow 락업**
- 출석 확인 → 주최자 정산 / 참가자 반환
- 노쇼 → 락업분 주최자 귀속
- **DORRIDATOR 시스템**: 스테이킹 기반 탈중앙화 신원 검증 (허위 검증 시 슬래싱)
- 밋업 → 대형 컨퍼런스 → 데이팅 → 프리랜서 매칭 → 커머스 확장

### XRPL 활용 방식
| 기능 | XRPL |
|------|------|
| 조건부 자산 락업 | **EscrowCreate/Finish/Cancel** |
| 자동 환전 | **Cross-Currency Payment** |
| 신원 증명 | **NFT 배지** |
| 토큰 발행 | **TrustLine IOU** |

### 📊 위협도: ⭐⭐⭐⭐ (높음)
> XRPL 네이티브 기능 4개 이상 활용. "에스크로-검증-정산" 구조가 깔끔. 3개월 로드맵 구체적. 크립토 네이티브 타겟이 해커톤 심사위원과 궁합 좋음.
